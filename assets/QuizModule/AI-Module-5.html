5.1 What is Deep Learning?

Deep Learning is a subset of Machine Learning based on Artificial Neural Networks with representation learning. The "Deep" in deep learning refers to the number of layers through which the data is transformed.

Neural Network Structure

  • Input Layer: Receives raw data (pixels, text tokens, sensory readings).
  • Hidden Layers: Performs mathematical transformations to identify complex features.
  • Output Layer: Provides the final prediction or decision.

5.2 Key Algorithms

Modern AI architectures are built on several foundational algorithms and structures:

  • Convolutional Neural Networks (CNN): Optimized for processing grid-like data (images).
  • Recurrent Neural Networks (RNN): Specialized for sequential data (time-series, text).
  • Transformers: The architecture behind LLMs, utilizing "Self-Attention" mechanisms to process data in parallel.
  • Generative Adversarial Networks (GANs): Two networks competing to create realistic synthetic data.
