5.1 Functions

Learn how to create modular and reusable code segments.

What is a Function?

A function is a reusable block of code that performs a specific task. Functions help divide large programs into smaller and manageable parts.

  • Help divide large programs into smaller parts
  • Make programs easier to write, understand, and maintain
  • Improve code reusability (write once, use many times)

The def keyword is used to define or create a function in Python.

Properties of def:

  • def stands for define
  • Function name is written immediately after the keyword
  • Always ends with a colon :

Errors in Parameters and Arguments

Mismatches between the number of parameters and arguments lead to errors.

Missing Argument Error

Occurs when fewer arguments are passed than required parameters.

Extra Argument Error

Occurs when more arguments are passed than required parameters.

Missing Argument Error
Python 
def add(a, b):
    print(a + b)

add(5)
Error
Python 
TypeError: add() missing 1 required positional argument: 'b'

Here, add() requires two parameters, a and b, but only one argument (5) was passed during the call. Python raises a TypeError because it cannot find a value for the missing parameter b.

Extra Argument Error
Python 
def add(a, b):
    print(a + b)

add(5, 6, 7)
Error
Python 
TypeError: add() takes 2 positional arguments but 3 were given

Here, add() only accepts two parameters, a and b, but three arguments (5, 6, 7) were passed during the call. Python raises a TypeError because there is no parameter to receive the extra value.

Default Values

Default values are predefined values assigned to parameters. If no argument is passed, the default value is used automatically.

Example

Here, name has a default value of "Student". When greet() is called with no argument, Python uses the default value. When greet("Anoop") is called, the passed value "Anoop" overrides the default.

A function can also return more than one value, separated by commas.

def student_info():

Docstrings

A Docstring is a special string used to explain what a function does. It is written inside triple quotes below the function definition.

Why Are Docstrings Used?

  • Explain the purpose of the function
  • Help programmers understand code
  • Improve readability
  • Useful in large projects
Example
Python 
def add(a, b):
    """This function adds two numbers"""
    return a + b
Try it out:

def add(a, b):
    """This function returns the sum of two numbers"""
    return a + b

print(add.__doc__)

This function returns the sum of two numbers

"""This function adds two numbers""" — this line explains the purpose of the function. It tells the programmer:

  • What the function does
  • Why the function is used

What is self?

self refers to the current object of the class. It is used to access variables and methods inside the class. Python automatically passes the current object to self. self helps methods identify which object is using them.

Why is self?

Example: A Classroom

Imagine a classroom. There are two students:

  • Anoop
  • Rahul

Both students can introduce themselves.

When Anoop speaks:
"I am Anoop"
When Rahul speaks:
"I am Rahul"

Here, "I" changes depending on who is speaking.

Similarly in Python

self means: "The current object using the method"

Real Life Python
"I am Anoop" self = anoop_object
"I am Rahul" self = rahul_object

When an object calls a method, self represents that object.

Example: Students in a Class

When student Anoop says "I am a student", and Rahul says "I am a student", the "I" refers to different people. In Python, self acts like "I".

Real LifePython
"I am Anoop"self = anoop_object
"I am Rahul"self = rahul_object

What Happens Behind the Scenes

When you call s1.introduce(), Python internally runs Student.introduce(s1), so self becomes s1. Likewise, s2.introduce() becomes Student.introduce(s2), so self becomes s2. This is how each object's method knows which object it belongs to.

s2.introduce("Rahul")

I am Rahul

Here, self always refers to the object the method was called on, while name is the extra value passed in — that's why s1.introduce("Anoop") prints Anoop and s2.introduce("Rahul") prints Rahul.

What is Unit Testing?

Unit testing is a technique used to check whether a function or a small part of a program works correctly. It compares the actual output of the code with the expected output. If both outputs are the same, the test passes. If the outputs are different, the test fails.

Actual
add(5,3)
==
Expected
8

Why Do We Need Unit Testing?

When we write code, we may think it is correct — but how do we confirm that? We could test manually using print(), but this becomes difficult once a program contains many functions. Unit testing automatically checks whether our code produces the correct result.

Example: The Exam

Question
5 + 3 = ?
Your Answer
8
Teacher's Answer
8

The teacher compares both answers — since they match:

Result: PASS

If your answer was 10 instead, comparing it to the correct answer of 8:

Result: FAIL

This is exactly how unit testing works in programming. Suppose you write:

Connecting to Programming
def add(a, b):
    return a + b

# Is my function working correctly?
self.assertEqual(add(5, 3), 8)

Testing Functions in Unit Testing

In unit testing, special functions are used to check whether the output of a program is correct. These functions compare the actual output with the expected output: if both outputs are the same, the test passes; if they differ, the test fails. These testing functions are called assertion methods.

Why Do We Need Testing Functions?

Consider the function:

Python 
def add(a, b):
    return a + b

We expect:

add(5, 3)

to return:

8

Python needs a way to compare:

  • Actual Output
  • Expected Output

For this purpose, unit testing provides assertion methods.

assertEqual()

assertEqual() checks whether two values are equal. It compares the actual output with the expected output. If both values are the same, the test passes. If the values are different, the test fails.

Syntax
