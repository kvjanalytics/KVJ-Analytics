3.1 Input and Output

Input

What is Input?

Input means giving data or information to a program.

In Python, users can enter data using the keyboard while the program is running.

input() Function

How input() Works

The input() function is used to take data from the user through the keyboard.

The value entered by the user is stored in a variable.

  • input() → function used to take input
  • "message" → text shown to the user
  • The entered value is returned and stored in a variable
name = input("Enter your name: ")
print("Hello,", name)
Enter your name: Rahul
Hello, Rahul

Default Datatype of input()

Always Returns String

The input() function stores all values as string (str) by default.

Even if the user enters:

  • numbers
  • decimal values

Python stores them as text.

# User types: 25
age = input("Enter your age: ")
print(type(age))   # <class 'str'>
<class 'str'>

Why Does input() Store Data as String?

Python treats keyboard input as text by default because users can enter:

  • letters
  • numbers
  • symbols

So Python safely stores everything as string.

Datatype Conversion

Datatype conversion means changing one datatype into another datatype.

Python provides built-in functions for conversion.

Common conversions:

  • int() → integer
  • float() → decimal number

int()

The int() function converts a string value into an integer.

age = int(input("Enter your age: "))
print(age + 5)
Enter your age: 20
25

Why int() is Important?

int() is mainly used for:

  • addition
  • subtraction
  • multiplication
  • division

because arithmetic operations need numeric datatype.

float()

The float() function converts a value into a decimal number.

price = float(input("Enter price: "))
print(price * 2)
Enter price: 9.5
19.0

Why float() is Important?

float() is important because it allows Python to work with decimal values.

It is mainly used when calculations contain:

  • decimal numbers
  • fractional values
  • accurate measurements

Multiple Inputs

Taking More Than One Input

Multiple inputs allow users to enter more than one value.

Programs often need multiple details from users.

name = input("Enter your name: ")
age  = int(input("Enter your age: "))
print(f"Hello {name}, you are {age} years old.")
Enter your name: Rahul
Enter your age: 22
Hello Rahul, you are 22 years old.

Output

What is Output?

Output means displaying information or results to the user.

Python uses the print() function to display output.

print() Function

What print() Can Display

The print() function is used to display:

  • text
  • numbers
  • variables
  • results

on the screen.

print("Hello, World!")
print(42)
x = 10
print(x)
Hello, World!
42
10

Output Formatting

Why Format Output?

Output formatting is used to display output in a neat and readable format.

It improves the appearance of program output.

Python provides:

  • string.format()
  • f-String

string.format()

The format() method inserts values into placeholders {} inside a string.

  • {} is called placeholder
  • format(name) inserts the value inside the placeholder
  • "Rahul" replaces {}
name = "Rahul"
sales = 5000
print("Employee: {}, Sales: {}".format(name, sales))
Employee: Rahul, Sales: 5000

f-String

f-String is a modern and simple method used for formatted output.

It uses:

  • f before the string
  • variables inside {}
name = "Rahul"
sales = 5000
print(f"Employee: {name}, Sales: {sales}")
Employee: Rahul, Sales: 5000

3.2 Command Line Argument

What are Command Line Arguments?

Command line arguments are values passed to a Python program while running the program from the command prompt or terminal.

These values are given after the Python file name.

Command line arguments help programs receive input directly during execution.

Example

Business Scenario

Suppose a company wants to generate reports for different employees.

Instead of changing the program every time, command line arguments can be used to pass the employee name directly:

# Run from terminal:
python report.py Rahul

Here: Rahul is the command line argument.

Why Command Line Arguments are Important?

Benefits

Command line arguments are useful because:

  • programs become flexible
  • users can give values directly
  • useful in automation
  • no need to modify code repeatedly

sys Module

Using sys.argv

Python provides the sys module to work with command line arguments.

The sys.argv list stores all arguments passed to the program.

import sys
print(sys.argv)

If executed as: python test.py Rahul 22

['test.py', 'Rahul', '22']
  • test.py → program name
  • Rahul → first argument
  • 22 → second argument

Python stores all values inside a list.

Default Datatype of Command Line Arguments

Always String by Default

All command line arguments are stored as string (str) datatype by default.

import sys
print(type(sys.argv[1]))   # <class 'str'>

Datatype Conversion

Converting Command Line Arguments

Datatype conversion means changing one datatype into another datatype.

In command line arguments, all values are stored as strings (str) by default.

To perform arithmetic operations like:

  • addition
  • subtraction
  • multiplication
  • division

the values must be converted into numeric datatypes such as int or float.

Otherwise, Python treats the values as text instead of numbers.

import sys
num1 = int(sys.argv[1])
num2 = int(sys.argv[2])
print(num1 + num2)

3.3 File Handling

What is File Handling?

File handling is an important part of any web application.

Python has several functions for creating, reading, updating, and deleting files.

Functions

The open() Function

The key function for working with files in Python is the open() function.

The open() function takes two parameters: filename, and mode.

File Opening Modes

There are four different methods (modes) for opening a file:

ModeNameDescription
"r"ReadDefault value. Opens a file for reading, error if the file does not exist
"a"AppendOpens a file for appending, creates the file if it does not exist
"w"WriteOpens a file for writing, creates the file if it does not exist
"x"CreateCreates the specified file, returns an error if the file exists
"t"TextDefault value. Text mode
"b"BinaryBinary mode (e.g. images)

In addition you can specify if the file should be handled as binary or text mode:

File Open

Open a File on the Server

Assume we have the following file, located in the same folder as Python:

# demofile.txt content:
Hello! Welcome to demofile.txt
This file is for testing purposes.

Using the with Statement

You can also use the with statement when opening a file:

with open("demofile.txt") as f:
    print(f.read())

Then you do not have to worry about closing your files, the with statement takes care of that.

Close Files

Always Close Your Files

It is a good practice to always close the file when you are done with it.

If you are not using the with statement, you must write a close statement in order to close the file:

f = open("demofile.txt", "r")
print(f.read())
f.close()
Note: You should always close your files. In some cases, due to buffering, changes made to a file may not show until you close the file.

Read Only Parts of the File

By default the read() method returns the whole text, but you can also specify how many characters you want to return:

f = open("demofile.txt", "r")
print(f.read(5))   # reads first 5 characters
Hello

File Write

Write to an Existing File

To write to an existing file, you must add a parameter to the open() function:

  • "a" — Append — will append to the end of the file
  • "w" — Write — will overwrite any existing content
# Append to existing file
f = open("demofile.txt", "a")
f.write("Now the file has more content!")
f.close()

Overwrite Existing Content

To overwrite the existing content to the file, use the w parameter:

f = open("demofile.txt", "w")
f.write("Woops! I have deleted the content!")
f.close()
Note: the "w" method will overwrite the entire file.

Create a New File

Creating Files

To create a new file in Python, use the open() method, with one of the following parameters:

  • "x" — Create — will create a file, returns an error if the file exists
  • "a" — Append — will create a file if the specified file does not exist
  • "w" — Write — will create a file if the specified file does not exist
# Create a new file
f = open("myfile.txt", "x")
Note: If the file already exists, an error will be raised.

Delete File

Deleting a File

To delete a file, you must import the OS module, and run its os.remove() function:

import os
os.remove("demofile.txt")
