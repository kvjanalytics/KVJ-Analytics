4.1 io Module

What is the io Module?

The io module is a built-in Python module used for handling input and output operations.

It helps programs:

  • Open files
  • Read files
  • Write files
  • Work with streams

The io module is mainly used in file handling and data processing.

Analogy: Think of a Notebook

Think of a notebook.

  • Writing inside the notebook → Output
  • Reading from the notebook → Input

Similarly, the io module helps programs write data and read data from files and streams.

Importing the io Module

Try it out:
Example
import io

print("io module imported")
Output
io module imported

Opening Files using io Module

The open() function is used to open files.

Syntax
open("file_name", "mode")
Try it out:
Example
import io

file = open("sample.txt", "w")
file.write("Hello Python")
file.close()
Output
File created successfully

write() Function

The write() function is used to write data into a file.

It stores information permanently inside the file

Syntax
file.write(data)
Try it out:
Example
import io

file = open("student.txt", "w")
file.write("Rahul")
file.close()
Output
Data written successfully

read() Function

The read() function is used to read the contents of a file.

It retrieves data stored inside the file.

Syntax
file.read()
Try it out:
Example
file = open("student.txt", "r")
print(file.read())
file.close()
Output
Rahul
Difference Between read() and write()
read() write()
Reads existing data Stores new data
Used to view file content Used to save file content
Requires read mode ( "r" ) Requires write mode ( "w" )

StringIO()

In-Memory Text Stream

StringIO() is used to create an in-memory text stream.

It behaves like a file but stores data in memory instead of a physical file.

Syntax
</> Python 
io.StringIO()
Try it out:
</> Example 
import io

text = io.StringIO()

text.write("Python")

print(text.getvalue())
OUTPUT
Python

randrange() Method

                


                

                    

                        The randrange() method returns a randomly selected element from the specified range.
                    


                    
                    

                        Syntax
                        

                            random.randrange(start, stop, step)
                        

                    


                    
                    

                        Parameter Values
                        

                            

                                
                                    

                                        Parameter
                                        Description
                                    

                                
                                
                                    

                                        start
                                        Optional. An integer specifying at which position to start. Default is 0.
                                    

                                    

                                        stop
                                        Required. An integer specifying at which position to end (not included).
                                    

                                    

                                        step
                                        Optional. An integer specifying the incrementation. Default is 1.
                                    

                                
                            

                        

                    


                    
                    

                        

                        

                            

                                
                                Example 1

choice() Method

                


                

                    

                        The choice() method returns a randomly selected element from the specified sequence.
                        
The sequence can be a string, a range, a list, a tuple, or any other kind of sequence.
                    


                    
                    

                        Syntax
                        

                            random.choice(sequence)
                        

                    


                    
                    

                        Parameter Values
                        

                            

                                
                                    

                                        Parameter
                                        Description
                                    

                                
                                
                                    

                                        sequence
                                        Required. A sequence like a list, a tuple, a range of numbers, or even a string.
                                    

                                
                            

                        

                    


                    

                        

                             More Examples
                        

                    


                    
                    

                        
                        

                            

                                
                                Example 1: Select from a List
                            

                            

                                
Return a random element from a list:

                            

                            

                                
import random

mylist = ["apple", "banana", "cherry"]
print(random.choice(mylist))

shuffle() Method

                


                

                    

                        The shuffle() method takes a sequence, like a list, and reorganizes the order of the items.
                    


                    

                        

                             Note: This method changes the original list; it does not return a new list.
                        

                    


                    
                    

                        Syntax
                        

                            random.shuffle(sequence)
                        

                    


                    
                    

                        Parameter Values
                        

                            

                                
                                    

                                        Parameter
                                        Description
                                    

                                
                                
                                    

                                        sequence
                                        Required. A sequence (like a list) to be shuffled.
                                    

                                
                            

                        

                    


                    
                    

                        
                        

                            

                                
                                Example: Shuffle a List
                            

                            

                                
Shuffle a list (reorganize the order of the items):

                            

                            

                                
import random

mylist = ["apple", "banana", "cherry"]
random.shuffle(mylist)
print(mylist)

                            

                            

                                
                                

                                     
 OUTPUT

                                     

                                

                            

                        

                    

                

            

            

            
            

                

                    
                    
sample() Method

                


                

                    

                        The sample() method returns a list with a specified number of randomly selected items from a sequence.
                    


                    

                        
    
                            
  •  This method does not change the original sequence.
    • 
                            
  •  The specified number (k) cannot be longer than the length of the original sequence.
    • 
                        

                    


                    
                    

                        Syntax
                        

                            random.sample(sequence, k)
                        

                    


                    
                    

                        Parameter Values
                        

                            

                                
                                    

                                        Parameter
                                        Description
                                    

                                
                                
                                    

                                        sequence
                                        Required. Any sequence (list, tuple, string, range, etc.)
                                    

                                    

                                        k
                                        Required. The size of the returned list.
                                    

                                
                            

                        

                    


                    
                    

                        
                        

                            

                                
                                Example: Pick a Sample
                            

                            

                                
Return a list that contains any 3 of the items from a list:

                            

                            

                                
import random

mylist = ["apple", "banana", "cherry", "mango", "grape"]
x = random.sample(mylist, 3)
print(x)

                            

                            

                                
                                

                                     
 OUTPUT
