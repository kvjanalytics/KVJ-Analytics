Data Manipulation & Transformation

2.1 The ETL Process

Before data can be analyzed, it often needs to be prepared. The ETL process is the backbone of data preparation:

ETL stands for:
  • Extract: Pulling raw data from its source (e.g., database, API, file).
  • Transform: Cleaning, reformatting, and restructuring data.
  • Load: Moving the processed data into a target system for analysis.

2.2 Common Data File Formats

Data analysts work with many file types. The most common include:

  • CSV (Comma-Separated Values): A plain text file where values are separated by commas. The most common format for tabular data.
  • JSON (JavaScript Object Notation): A key-value format used heavily in web APIs and NoSQL databases.
  • XML (Extensible Markup Language): Uses tags to define structure, common in enterprise systems.
  • XLSX: Microsoft Excel format with support for multiple sheets and formatting.

2.3 Data Cleaning Techniques

Real-world data is rarely perfect. Common issues include missing values, duplicates, inconsistent formatting, and extra whitespace. Data cleaning is the process of fixing these issues.

Handling Missing Values (Nulls)

Missing values can be handled by:

  • Removing rows or columns with too many missing values.
  • Filling missing values with a default, the mean, or the median.
  • Flagging missing values for later review.
# Example: Filling missing values
data = [10, None, 30, None, 50]
clean = [x if x is not None else 0 for x in data]
print(clean)
[10, 0, 30, 0, 50]

Trimming Whitespace

Extra spaces can cause matching errors. Use .strip() to trim them.

name = "  KVJ Analytics  "
print(name.strip())
KVJ Analytics

Removing Duplicates

Duplicate records can skew your analysis. In Python, set() removes duplicates from a list.

ids = [101, 102, 101, 103, 102]
unique_ids = list(set(ids))
print(unique_ids)
[101, 102, 103]

2.4 Data Aggregation

Aggregation means combining individual data points into summarized values. Common aggregation functions include:

  • SUM: Total of all values.
  • COUNT: Number of records.
  • AVG (Mean): Sum / Count.
  • GROUP BY: Splitting data into groups to apply aggregation per group.
Real-world Example:

A retail company groups sales by region to find which area generates the most revenue. This is a GROUP BY + SUM operation.
