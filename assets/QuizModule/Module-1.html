1.1 Introduction

What is Python?

Python is a powerful and easy-to-learn programming language created by Guido van Rossum and officially released in 1991. Its simple syntax and versatility make it one of the most widely used languages in the world.

Python is commonly used for:

  • Web application development
  • Software and application development
  • Data analysis and mathematics
  • Automation and scripting tasks

What Can Python Do?

Python helps developers build a wide range of applications and solutions efficiently.

With Python, you can:

  • Develop dynamic websites and web applications
  • Automate repetitive workflows and processes
  • Connect with databases and manage files
  • Analyze large datasets and perform advanced calculations
  • Build scalable and production-ready software solutions

Why Choose Python?

Python is popular among beginners and professionals because of its simplicity, flexibility, and wide industry adoption.

Key advantages of Python:

  • Works across multiple platforms such as Windows, macOS, and Linux
  • Uses clean and readable syntax that is easy to understand
  • Reduces development time with concise and efficient code
  • Supports rapid prototyping and faster application development
  • Has a large community and extensive library ecosystem

Casting in python is therefore done using constructor functions:

  • int() - constructs an integer number from an integer literal, a float literal (by removing all decimals), or a string literal (providing the string represents a whole number)
  • float() - constructs a float number from an integer literal, a float literal or a string literal (providing the string represents a float or an integer)
  • str() - constructs a string from a wide variety of data types, including strings, integer literals and float literals

Changeable

We can change, add or remove items after the dictionary has been created.

No Duplicates

Dictionaries cannot have two items with the same key.

Removing Items

There are several methods to remove items from a dictionary. The pop() method removes the item with the specified key name. The del keyword removes the item with the specified key name, or it can also delete the dictionary completely. The clear() method empties the dictionary.

Copy a Dictionary

You cannot copy a dictionary simply by typing dict2 = dict1, because dict2 will only be a reference to dict1. Use the built-in Dictionary method copy(), or use the built-in function dict().

1.5 White Space

White space refers to the empty spaces used in a Python program to improve readability and code organization. While Python uses indentation (a type of white space) to define blocks of code, other types of white space are optional but highly recommended for clarity.

Why use White Space?

  • Makes code cleaner and easier to understand
  • Helps distinguish between operators and operands
  • Improves overall project maintainability

White Space Around Operators

Spaces are commonly added around operators (like +, -, =) to improve readability.

Without Spaces (Harder to read)
a=10+20
print(a)
With Spaces (Clean & Readable)
a = 10 + 20
print(a)

White Space in Variables

Using white space correctly when declaring multiple variables makes it easier to scan the code.

Example 1
name="Rahul"
age=22
salary=25000.50
Example 2
name = "Rahul"
age = 22
salary = 25000.50

White Space in Data Structures

Adding spaces after commas in lists or other collections is a best practice for readability.

Congested List
numbers=[10,20,30,40]
Readable List
numbers = [10, 20, 30, 40]
