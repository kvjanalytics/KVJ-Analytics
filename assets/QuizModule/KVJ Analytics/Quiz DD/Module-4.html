4.1 io Module

What is the io Module?

The io module is a built-in Python module used for handling input and output operations.

It helps programs:

  • Open files
  • Read files
  • Write files
  • Work with streams

The io module is mainly used in file handling and data processing.

Analogy: Think of a Notebook

Think of a notebook.

  • Writing inside the notebook → Output
  • Reading from the notebook → Input

Similarly, the io module helps programs write data and read data from files and streams.

Importing the io Module

import io

Opening Files using io Module

The open() Function

The open() function is used to open files.

import io

file = open("example.txt", "w")
file.write("Hello, World!")
file.close()

write() Function

Writing Data to a File

The write() function is used to write data into a file.

It stores information permanently inside the file.

import io

file = open("data.txt", "w")
file.write("Python is amazing!")
file.close()
print("Data written successfully")
Data written successfully

read() Function

Reading Data from a File

The read() function is used to read the contents of a file.

It retrieves data stored inside the file.

import io

file = open("data.txt", "r")
content = file.read()
print(content)
file.close()
Python is amazing!

StringIO()

In-Memory Text Stream

StringIO() is used to create an in-memory text stream.

It behaves like a file but stores data in memory instead of a physical file.

import io

stream = io.StringIO()
stream.write("Hello from memory!")
stream.seek(0)
print(stream.read())
Hello from memory!

4.4 datetime Module

What is the datetime Module?

The datetime module is a built-in Python module used to work with:

  • Date
  • Time
  • Day
  • Year

It helps programs manage and display date and time information.

datetime Module Methods

MethodDescription
now()Returns current date and time
strftime()Formats date and time
weekday()Returns day number of week

now()

Current Date and Time

now() returns the current date and current time of the system.

from datetime import datetime

current = datetime.now()
print(current)
2024-01-15 10:30:45.123456

strftime()

Format Date and Time

The datetime object has a method for formatting date objects into readable strings.

The method is called strftime(), and takes one parameter, format, to specify the format of the returned string.

from datetime import datetime

now = datetime.now()
formatted = now.strftime("%Y-%m-%d %H:%M:%S")
print(formatted)
2024-01-15 10:30:45

weekday()

Day Number of the Week

weekday() returns the day number of the week.

Note: Monday = 0, Tuesday = 1, ..., Sunday = 6
from datetime import datetime

today = datetime.now()
day_num = today.weekday()
print(day_num)
0

4.5 random Module

What is the random Module?

The random module is a built-in Python module used to generate random values.

It helps programs:

  • Generate random numbers
  • Select random items
  • Shuffle data

randrange() Method

Python Random randrange() Method

The randrange() method returns a randomly selected element from the specified range.

Parameter Values

ParameterDescription
startOptional. An integer specifying at which position to start. Default is 0
stopRequired. An integer specifying at which position to end (not included)
stepOptional. An integer specifying the incrementation. Default is 1
 
import random

x = random.randrange(3, 9)
print(x)
5 # (a random number between 3 and 8)

randint() Method

Python Random randint() Method

The randint() method returns a random integer between the specified integers (both endpoints are included).

import random

x = random.randint(1, 10)
print(x)
7 # (a random number between 1 and 10)

choice() Method

Python Random choice() Method

The choice() method returns a randomly selected element from the specified sequence.

The sequence can be a string, a range, a list, a tuple or any other kind of sequence.

import random

fruits = ["apple", "banana", "cherry"]
x = random.choice(fruits)
print(x)
banana # (a randomly selected fruit)

shuffle() Method

Python Random shuffle() Method

The shuffle() method takes a sequence, like a list, and reorganizes the order of the items.

Note: This method changes the original list, it does not return a new list.
import random

mylist = ["apple", "banana", "cherry"]
random.shuffle(mylist)
print(mylist)
['cherry', 'apple', 'banana'] # (order is randomized)
