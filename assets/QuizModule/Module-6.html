6.1 Error Analysis & Detection

Identify and understand different types of errors in Python

What are Errors?

An error is a problem in a program that causes it to behave incorrectly or stop execution. Errors can prevent a program from running properly.

Key Points About Errors

  • Can prevent a program from running properly
  • Some errors stop the program immediately
  • Others produce incorrect results
  • Finding and correcting errors is essential

Why Should We Learn About Errors?

  • Helps identify problems in programs
  • Improves debugging skills
  • Makes programs reliable
  • Produces correct output
  • Helps write better code

Types of Errors in Python

Python has three main types of errors:

Error Type When It Occurs Example
Syntax Error Before execution (breaks Python rules) Missing colon or bracket
Logic Error During execution (wrong result) Using - instead of +
Runtime Error During execution (unexpected problem) Division by zero

Syntax Errors

A syntax error occurs when Python rules are not followed correctly. The program cannot run until the error is fixed.

Characteristics

  • Program cannot run
  • Python detects before execution
  • Usually caused by missing symbols
  • Incorrect keywords or structure

Example 1: Missing Closing Bracket

print("Hello"
# ❌ SyntaxError: Missing closing parenthesis
❌ Error: SyntaxError
Reason: The closing parenthesis is missing

Correct Code:

print("Hello")
Hello

Example 2: Missing Colon

if 5 > 3
    print("Hello")
# ❌ SyntaxError: Missing colon after if statement
❌ Error: SyntaxError
Reason: Missing colon (:) after if condition

Correct Code:

if 5 > 3:
    print("Hello")
Hello

Logic Errors

A logic error occurs when the program runs successfully but produces the wrong output. Python does not display an error message.

Characteristics

  • Program executes normally
  • No error message displayed
  • Wrong output produced
  • Programmer's logic is incorrect

Example: Wrong Operator

a = 10
b = 5

print(a - b)  # Using - instead of +
5
Expected Output: 15
Actual Output: 5
Problem: Used - (minus) instead of + (plus)

Correct Code:

a = 10
b = 5

print(a + b)  # Correct operator
15

Real-Life Example

Question: 10 + 5 = ?

Student's Answer: 5

The answer is wrong, but there is no grammar mistake. This is similar to a logic error in programming.

Runtime Errors

A runtime error occurs while the program is running. The code may be syntactically correct, but an unexpected problem occurs during execution.

Characteristics

  • Code is syntactically correct
  • Error occurs during execution
  • Python stops execution
  • Error message is displayed

Example 1: Division by Zero

num = 10

print(num / 0)
❌ Error: ZeroDivisionError
Reason: Division by zero is not allowed in mathematics

Correct Code:

num = 10

print(num / 2)
5.0

Example 2: Index Out of Range

numbers = [1, 2, 3]

print(numbers[5])
❌ Error: IndexError
Reason: Index 5 does not exist (list has only 0, 1, 2 indices)

Correct Code:

numbers = [1, 2, 3]

print(numbers[2])  # Valid index

Comparison of Error Types

Error Type Program Runs? Output Correct? Example
Syntax Error No No Missing : or )
Logic Error Yes No Wrong formula
Runtime Error Starts but stops No Division by zero

Summary

Error Type Description
Syntax Error Violation of Python rules
Logic Error Wrong program logic
Runtime Error Error during execution

6.2 Exception Handling

Handle errors gracefully to prevent program crashes

What is Exception Handling?

Exception handling is a technique used to handle errors that occur while a program is running. It prevents the program from stopping unexpectedly.

Key Benefits

  • Prevents program from crashing
  • Handles errors gracefully
  • Continues execution after error
  • Improves program reliability

Why Do We Need Exception Handling?

Sometimes users enter incorrect input or unexpected situations occur. Exception handling helps manage these situations without breaking the program.

Exception Handling Keywords

Python provides five important keywords for exception handling:

  • try - Contains code that may produce an error
  • except - Handles errors from try block
  • else - Executes if no error occurs
  • finally - Always executes regardless of error
  • raise - Manually generates an exception

try Statement

The try block contains code that may produce an error. Python first executes the code inside the try block. If no error occurs, execution continues normally. If an error occurs, Python moves to the except block.

Syntax:

try:
    # code that may have an error
except:
    # handling code

Example:

try:
    print(10 / 0)
except:
    print("Error Occurred")
Error Occurred

Explanation

What Happens:

  • Python tries to execute: 10 / 0
  • Division by zero causes an error
  • Instead of crashing, Error Occurred is displayed
  • Program continues execution

except Statement

The except block handles errors generated in the try block. It executes only when an exception occurs. Different errors can be handled using different except blocks.

Example: Specific Error Handling

try:
    print(10 / 0)
except ZeroDivisionError:
    print("Cannot divide by zero")
Cannot divide by zero

How It Works

  • ZeroDivisionError is detected
  • The matching except block executes
  • Program handles the error gracefully
  • Execution continues safely

else Statement

The else block executes only when no error occurs in the try block. If an exception occurs, the else block is skipped.

Example:

try:
    print(10 / 2)
except ZeroDivisionError:
    print("Error")
else:
    print("Division Successful")
5.0
Division Successful

Explanation

  • No error occurs in try block
  • Therefore, else block executes
  • Output includes both results

finally Statement

The finally block always executes whether an error occurs or not. It is commonly used for cleanup tasks.

Example:

try:
    print(10 / 2)
except:
    print("Error")
finally:
    print("Program Finished")
5.0
Program Finished

Key Point

The finally block executes regardless of whether an error occurred. This is useful for cleanup tasks like closing files or resources.

raise Statement

The raise statement is used to generate an exception manually. Programmers use it to create their own error conditions and enforce program rules.

Example: Validate User Input

age = -5

if age < 0:
    raise ValueError("Age cannot be negative")
❌ Error Output:
ValueError: Age cannot be negative

When to Use raise

  • Enforce program rules
  • Validate user input
  • Create meaningful error messages
  • Prevent invalid operations

Complete Exception Handling Program

Here's a real-world example that combines all exception handling concepts:

try:
    num = int(input("Enter a number: "))
    result = 10 / num

except ZeroDivisionError:
    print("Cannot divide by zero")

except ValueError:
    print("Please enter a valid number")

else:
    print("Result = ", result)

finally:
    print("Program Finished")

How This Program Works

  1. try block: Gets user input and performs division
  2. ZeroDivisionError except: Handles division by zero
  3. ValueError except: Handles non-numeric input
  4. else block: Displays result if no error
  5. finally block: Always prints completion message

Keyword Purpose

except Handles specific errors from try block

finally Always executes regardless of errors
