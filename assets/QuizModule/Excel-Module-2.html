2.3 Logical Functions

Mastering Conditional Architecture

Strategic Logic

Logical functions allow your data models to make decisions automatically. By chaining IF, AND, OR, and NOT, you transform static data into intelligent, dynamic business rules.

Core Logical Functions

FUNCTION

=IF()

Evaluates a logical condition and returns one specific value if TRUE, and another value if FALSE. This is the foundation of conditional logic.

Syntax

=IF(logical_test, [value_if_true], [value_if_false])

Example

Business Case: Tag product inventory as "Reorder" if stock drops below 50 units.

=IF(B2 < 50, "Reorder", "Sufficient")

Outcome

Returns "Reorder" if the stock level in B2 is 49 or lower; otherwise returns "Sufficient".

FUNCTION

=AND()

Evaluates multiple logical conditions simultaneously. Returns TRUE only if all provided conditions are TRUE. Frequently nested inside an IF statement.

Syntax

=AND(logical1, [logical2], ...)

Example

Business Case: Calculate a 10% bonus only if a salesperson exceeded sales goals AND maintained perfect attendance.

=IF(AND(Sales > 100000, Attendance = "100%"), Salary * 0.10, 0)

Outcome

Returns the 10% bonus amount only if BOTH conditions are met. If either condition fails, it returns 0.

FUNCTION

=OR()

Evaluates multiple logical conditions simultaneously. Returns TRUE if at least one of the provided conditions is TRUE.

Syntax

=OR(logical1, [logical2], ...)

Example

Business Case: Flag an account for review if the payment is over 30 days late OR the outstanding balance exceeds ₹50,000.

=IF(OR(Days_Late > 30, Balance > 50000), "Review Account", "Good Standing")

Outcome

Returns "Review Account" if EITHER condition triggers. It only returns "Good Standing" if neither condition is present.
