1. Meaning of Data

Foundational Definitions

Concept

Data refers to raw facts, figures, or observations collected for analysis or reference. Data can appear in many forms such as:

  • Numbers
  • Text
  • Images
  • Audio

By itself, data does not carry meaning until it is processed and interpreted.

Example Raw Data:
Product Sales
Laptop15
Tablet8
Phone20

After analysis we might discover: Phone is the best-selling product. That insight becomes useful information.

Insight:

Data is like ingredients in cooking. Ingredients alone do not create a meal. Only after processing and combining them do we get something meaningful.

3. Data Variable Types

Concept

Variables describe the type of value stored in data. Main variable types include Boolean, Numeric, and String. Each type stores different kinds of values.

Insight:

Understanding variable types helps store data correctly, analyze data efficiently, and avoid calculation errors.

3.1 Boolean Data Type

Boolean data type stores two possible values: True or False. Booleans are commonly used in logical conditions and decision making.

# Example:
is_logged_in = True
if is_logged_in:
    print("Access granted")
Insight:

Boolean variables act like switches: ON = True, OFF = False.

3.2 Numeric Data Type

Numeric data types represent numbers that can be calculated mathematically. Examples: exam marks, salary, weight, height. Numeric types include Integer, Float, Complex.

Insight:

Numeric data allows operations such as addition, subtraction, multiplication, and division.

3.3 Integer

An integer is a whole number without decimal values. Examples: 5, 10, -3, 0. Integers represent quantities like number of students or products sold.

Insight:

Integers are useful when exact counts are needed.

3.4 Float

A float represents numbers with decimal values. Examples: 2.5, 3.14, 7.8. Float values are used when precision is required (e.g., price, temperature, weight).

Insight:

Floats allow more accurate measurements compared to integers.

3.5 Complex Numbers

Complex numbers contain a real part and an imaginary part. General form: a + bi. Example: 3 + 4i. Python supports complex numbers using the complex data type.

Insight:

Complex numbers are mainly used in engineering and scientific calculations.

3.6 String Data Type

String data type stores text values. Examples: names, city, product names. Strings can contain letters, numbers, and symbols.

# Example:
name = "Anoop"
Insight:

Strings help store descriptive information, not numeric calculations.

5. Types of Data

Data can be classified into two main types: Qualitative data and Quantitative data.

5.1 Qualitative Data

Qualitative data describes categories or characteristics. Examples: gender, city, brand. Types include Nominal and Ordinal.

Insight:

Qualitative data focuses on descriptions rather than numbers.

6. Structured vs Unstructured Data

Structured Data

Structured data fits into rows and columns and is typically stored in databases or spreadsheets. Examples: phone numbers, bank records.

Unstructured Data

Unstructured data has no fixed format. Examples: emails, videos, social media posts.

Insight:

Most modern data generated online is unstructured.

7. Metadata

Concept

Metadata means data about data. It describes information such as file size, creation date, author, format.

Example:

A photo file may include metadata: camera type, date taken, resolution.

Insight:

Metadata helps organize and manage data efficiently.

Practice Activity: Metadata

8. Big Data

Concept

Big Data refers to extremely large and complex datasets that grow rapidly and cannot be processed using traditional systems. Sources of big data include social media, online transactions, sensors, and IoT devices.

Insight:

Big data allows organizations to analyze massive amounts of information to discover patterns and predictions.
